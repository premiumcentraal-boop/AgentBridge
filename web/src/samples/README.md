# Fictional demonstration recording

`sample-call.mp3` is an original scripted example, generated locally with FFmpeg/libflite stock `awb` and `slt` voices. It does not contain a real caller, Grok voice, real booking, phone number or microphone recording. Agent and recipient occupy separate stereo channels. `sample-call.json` has the aligned transcript and the explicit demonstration notice. The sample is bundled locally; playback sends no audio to an external service.
