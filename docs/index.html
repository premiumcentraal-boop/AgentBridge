Overview

AgentBridge's backend is a reference implementation for authenticated, one-time international telephone forwarding. The public site is a design preview. Carrier API keys, a US DID, live quote data, database setup and a verified Grok Bot account are required for a real deployment.

Remote MCP tools

prepare_international_call validates an E.164 destination, checks allowlisted countries and reserves a short-lived route. It returns the US access number, expiration and safety information. get_call_status reads a reservation. cancel_international_call cancels an unused reservation.

{ "tool": "prepare_international_call",
  "arguments": {
    "destination": "+31201234567",
    "idempotency_key": "example-unique-id"
  }
}

This is an example, not a live request. The backend requires a scoped bearer token and an assigned DID.

REST interface

POST /v1/reservations prepares a call. GET /v1/reservations/:id returns state. POST /v1/reservations/:id/cancel cancels it. GET /health reports non-sensitive service health.

POST /v1/reservations
Authorization: Bearer <server-issued-token>
Content-Type: application/json

{ "destination": "+31201234567",
  "idempotency_key": "unique-request-key" }

Call lifecycle

Ready → Connecting → Completed / Failed, with an expiry state for unused reservations. Incoming carrier events are authenticated and must atomically claim the appropriate reservation. No ready route should remain valid indefinitely.

Security and privacy

Never expose provider keys to browser JavaScript. Require authenticated owner authorization. Reject restricted countries and premium destinations. Verify telephony webhook signatures. Never trust Caller ID as the only authentication factor. Limit call duration and spending, reconcile charges, audit transitions, and avoid retaining call audio.

The prototype is deliberately fail-closed until configured. It is not a completed billing, compliance or abuse-prevention service. It should not be exposed for paid public use without the release gates in the North Star.

Deployment

The repository contains a Cloudflare Worker reference backend, D1 schema, setup instructions and test suite. Read README.md and NORTH_STAR.md before provisioning carrier resources.
