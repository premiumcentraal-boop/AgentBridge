# AgentBridge mobile review

Open https://agentbridge-worldwide.premiumcentraal.chatgpt.site on your phone.
Sign in with the Site owner's ChatGPT account if prompted. The homepage shows
“connect agents worldwide” and country lines connecting into calls. Choose
**Open studio** to explore the app; page links and interactions are real DOM
components, not screenshots. Two coloured lines with moving country flags enter
from opposite edges, glide and accelerate into the centre. Their contact
triggers a green pulse, a phone pop and a check mark that draws on as the lines
fade. The **Call connected** confirmation clears before the next pair starts,
so no earlier call icon appears during an approach. Twelve
pairings repeat over a 60-second cycle. New pairs always paint above the older
lines and icons, including when the loop restarts. This graphic is an illustration.

The Site is an owner-private static review, separate from the production
Railway service. Drafts, preferences and call controls are sample interactions
held in the current tab. No operator API, private records, keys or carrier
functionality are deployed to the review Site.

The preview serves the working React/Astryx HTML bundle, with ordinary hash
links to its pages. Historical boards load separately when requested so the
mobile entry stays small. Flags render as local SVG symbols inside white circles,
and their license notices are bundled locally.

## Calling extensions

Use **Features** to explore International Calling, optional Recording &
Transcription, and Let me join. In **Calls**, save a sample international plan.
The sample call lets you join muted, speak/leave in the simulation, request
optional capture and pause recording. **Recordings & transcripts** contains a
fictional synthetic sample with a real audio player, searchable transcript,
speaker filtering, timestamp navigation and downloads. Capture/join defaults
can be changed and retained while navigating the sample studio.

The static Site keeps all changes in the current tab. The Node service provides
authenticated SQLite persistence for call plans and preferences. Neither mode
adds live carrier calling, media capture or conference participation. Live use
requires additional authorized integration; sample actions contact no carrier
and request no microphone or callback.
